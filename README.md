# 错题重做

一个轻量、私密、无需服务器的本地错题复习系统。

它把“截图收集错题”和“按计划重新做题”放在同一个工具里：题目图片、答案图片和复习进度都保存在你自己选择的电脑文件夹中，不需要注册账号，也不用把学习资料上传到云端。

## 为什么值得用

- **隐私优先**：数据只写入你授权的本地题库文件夹，不依赖登录、数据库或在线服务。
- **录入足够快**：在题目区或答案区点击一下，直接按 `Ctrl + V` 粘贴截图；每道题最多支持 5 张题目图片和 5 张答案图片。
- **复习更有节奏**：系统会优先安排到期、答错或较久未复习的题目。答对后按 `1 / 3 / 7 / 14 / 30` 天逐步延长间隔，答错则约 1 天后再次出现。
- **数据掌握在自己手里**：题库是本地文件夹中的 JSON 和图片文件，清晰、可迁移、易备份，不会被某个平台锁定。
- **写入更稳妥**：题库采用双版本题目文件、写入后校验和恢复暂存机制；数据管理页还提供备份、覆盖恢复、快速检查和深度检查。
- **对大截图更友好**：图片会在本地进行尺寸处理和压缩，减少超大截图带来的存储压力，同时保留清晰的复习效果。
- **开箱即用**：项目没有构建步骤和第三方依赖，打开页面即可开始使用；桌面端和移动端页面也做了适配。

## 快速开始

### 1. 启动项目

正式入口是 [`index.html`](index.html)。推荐在项目目录启动一个本地静态服务器：

```bash
python -m http.server 8000
```

然后在浏览器打开 <http://localhost:8000/>。

项目不需要执行 `npm install`，也没有额外的构建流程。若电脑使用 `py` 命令，也可以运行：

```bash
py -m http.server 8000
```

### 2. 连接本地题库

1. 点击“选择错题数据文件夹”。
2. 选择一个空文件夹，或选择已有的本项目题库文件夹。
3. 在浏览器弹出的权限窗口中允许读写。

第一次选择空文件夹时，应用会自动创建题库所需文件。浏览器会记住最近使用的文件夹，之后可以直接重新连接；如果浏览器要求授权，重新允许即可。

### 3. 录入一道错题

1. 进入“录入错题”。
2. 点击“题目图片”区域，按 `Ctrl + V` 粘贴题目截图。
3. 点击“答案图片”区域，按 `Ctrl + V` 粘贴答案或解析截图。
4. 确认两边至少各有 1 张图片后，点击“保存错题”。

目前支持 `PNG`、`JPEG`、`WebP` 图片；每组最多 5 张。图片会保存到题库文件夹的 `images` 子目录中。

### 4. 开始复习

进入“开始复习”后，先看题目，再点击“查看答案”，根据实际作答情况选择：

- **答对**：逐步延长下一次复习间隔；
- **答错**：重置连续答对次数，并在较短时间后再次安排；
- **不再显示**：将题目移出随机复习，但不会删除图片文件。

如果暂时没有到期题目，系统会提示当前复习已完成，等下一次到期后再继续即可。

### 5. 管理和保护数据

在“数据管理”中可以查看题目数、图片数、数据大小和当前题库版本，并使用：

- **备份题库**：将题库逐文件复制到另一个本地文件夹；
- **从备份覆盖恢复**：先校验备份，再将其恢复到当前题库；
- **快速完整性检查**：检查 JSON、题目结构、图片是否存在等基础问题；
- **深度检查**：在快速检查基础上进一步尝试解码图片。

恢复操作会覆盖当前题库，建议在恢复前先做一次备份。备份和恢复都不会上传数据，也不会生成必须依赖特定软件才能打开的压缩包。

## 题库文件结构

题库由你选择的文件夹承载，大致结构如下：

```text
你的题库文件夹/
├─ app.json              # 题库标识、数据版本和时间信息
├─ questions-a.json      # 题目数据版本 A
├─ questions-b.json      # 题目数据版本 B
├─ images/               # 题目图片和答案图片
└─ recovery/             # 恢复操作产生的安全副本
```

这种设计让题库既方便整体复制，也能在单个题目文件异常时尽量保留另一份可用版本。除非你清楚数据格式，否则不建议手动修改或删除这些文件。

## 使用前提

项目使用浏览器的本地文件夹访问能力。建议使用较新的 Chromium 内核浏览器，例如 Chrome 或 Edge，并通过 `http://localhost` 或 HTTPS 访问。Firefox、Safari 以及直接双击 HTML 文件打开时，文件夹读写能力可能不可用或表现不一致。

## 项目文件

```text
index.html              # 正式应用入口，包含本地题库和复习逻辑
错题重做.html           # 早期界面演示页，不是正式数据入口
assets/                 # Logo 等静态资源
tests/                  # 复习算法测试
```

## 适合谁

如果你习惯用截图保存错题，又不想把学习资料交给云端平台，错题重做可以作为一个简单可靠的“个人错题文件柜 + 复习提醒器”。它不追求复杂的功能堆叠，而是把隐私、速度、数据可控和持续复习这几件最重要的事做好，让错题真正从“收藏过”变成“重新做会”。
